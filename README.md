# TrackingSpellLOL


## Overview
A lightweight, non-intrusive Windows desktop overlay for League of Legends. It automatically synchronizes champion identity, position, and Summoner Spells via the official local League Live Client Data API (`https://127.0.0.1:2999`).

Cooldown timers remain strictly **MANUAL CLICK TIMERS** to comply with Riot Games third-party application policies.

## Features
- **Compact HUD & Team Customization**:
  - Champion Portrait + Summoner Spell 1 + Summoner Spell 2 (+ Top Role Quest Teleport Slot)
- **Automatic Live Client API Synchronization**: Connects safely to `127.0.0.1:2999`.
- **Riot Policy Compliance**: No process memory scanning, no DLL injection, no packet sniffing, no automatic spell cast detection.
- **Spell-Specific Cooldowns**: Supports Flash, Teleport, Ignite, Heal, Exhaust, Barrier, Cleanse, Ghost, and Smite.
- **Summoner Haste Calculation**: Auto-detects Cosmic Insight and Ionian Boots.

## How to Run
Simply double-click `TrackingSpellLOL.exe`.

## Tray Menu
- Show / Hide Overlay
- Display Team (Enemy Team / My Team / Both)
- HUD Scale (80% - 160%)
- Lock Position (Khoá vị trí HUD)
- Opacity Adjustment (20% - 100%)
- Reset All Timers

# TrackingSpellLOL

## Tổng quan
Một ứng dụng overlay siêu nhẹ và không can thiệp dành cho Liên Minh Huyền Thoại trên Windows. Ứng dụng tự động đồng bộ hóa thông tin tướng, vị trí và Phép Bổ Trợ thông qua Live Client Data API chính thức của League (`https://127.0.0.1:2999`).

Bộ đếm thời gian hồi chiêu hoàn toàn là **BỘ ĐẾM BẤM THỦ CÔNG** để tuân thủ chính sách dành cho ứng dụng bên thứ ba của Riot Games.

## Tính năng
- **Giao diện HUD Nhỏ Gọn & Tùy Chỉnh Đội**:
  - Chân dung Tướng + Phép Bổ Trợ 1 + Phép Bổ Trợ 2 (+ Ô Dịch Chuyển Nhiệm Vụ Đường Trên)
- **Tự Động Đồng Bộ Live Client API**: Kết nối an toàn tới `127.0.0.1:2999`.
- **Tuân Thủ Chính Sách của Riot**: Không quét bộ nhớ tiến trình, không inject DLL, không bắt gói tin, không tự động phát hiện dùng phép.
- **Thời Gian Hồi Chiêu Theo Phép**: Hỗ trợ Tốc Biến, Dịch Chuyển, Thiêu Đốt, Hồi Máu, Kiệt Sức, Lá Chắn, Thanh Tẩy, Tốc Hành và Trừng Phạt.
- **Tự Động Tính Điểm Hồi Phép**: Tự động nhận diện Ngọc Vũ Trụ (Cosmic Insight) và Giày Khai Sáng Ionia.

## Hướng dẫn sử dụng
