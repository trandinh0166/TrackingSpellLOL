# TrackingSpellLOL
TrackingSpellLOL is a lightweight, non-intrusive Windows overlay for League of Legends designed to track enemy Summoner Spells accurately in real time.
TrackingSpellLOL là ứng dụng overlay siêu nhẹ trên Windows dành cho Liên Minh Huyền Thoại, giúp theo dõi thời gian hồi Phép Bổ Trợ của đối phương một cách chính xác và trực quan.
