# Version 2.0 Changelog

- Added automatic champion synchronization via Live Client Data API.
- Added automatic position synchronization (TOP, JUNGLE, MID, AD, SUP).
- Added dual Summoner Spell synchronization per player row.
- Added Data Dragon champion portrait & spell icon caching (`assets/champions`, `assets/summoner`).
- Redesigned layout to 3 Columns x 5 Player Rows (45% Champion, 27.5% Spell 1, 27.5% Spell 2).
- Added JSON-driven spell database (`data/summoner_spells.json`).
- Added Teleport contextual cooldown support and Smite charge model support.
- Added GameSessionManager to reset session timers when a new game starts.
- Added Display Team settings (My Team, Enemy Team, Both).
- Maintained strict Riot Policy Compliance (100% manual click timers).
