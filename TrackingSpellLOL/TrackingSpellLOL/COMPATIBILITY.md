# COMPATIBILITY & SYSTEM REQUIREMENTS

- **Operating System**: Windows 10 / Windows 11 (64-bit).
- **Game Version**: League of Legends PC (Season 2024+).
- **Riot Vanguard**: 100% Compatible. Operates entirely out-of-process using official local HTTP endpoints.
- **Game Modes Supported**: Summoner's Rift (5v5 Rank/Normal), ARAM, Arena, Nexus Blitz.
